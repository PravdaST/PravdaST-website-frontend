Това е последната грешка, свързана с Meta Pixel. Тя е директен резултат от предишната ни поправка, която беше правилна, но сега изисква да довършим нещата по правилния начин.

Проблем
Файл с грешка: ../src/components/meta-pixel.tsx, ред 32.

Причина: Type error: Property 'loaded' does not exist on type '(...args: any[]) => void'.

На прост език: След като инсталирахме официалните типове (@types/facebook-pixel), TypeScript вече знае, че window.fbq е функция, а не обект, към който можете да добавяте свойства като .loaded, .version или .queue. Вашият код се опитва да направи точно това и TypeScript с право го спира.

Решението
Трябва да пренапишете meta-pixel.tsx компонента, така че да използва стандартния начин за инициализация на Meta Pixel, без да се опитвате да променяте fbq функцията.

Отворете файла src/components/meta-pixel.tsx.

Заменете цялото му съдържание със следния, по-чист и модерен код:

TypeScript

'use client'

import { usePathname } from 'next/navigation'
import Script from 'next/script'
import { useEffect, useState } from 'react'

// Вземете ID-то от променливите на средата
const PIXEL_ID = process.env.NEXT_PUBLIC_META_PIXEL_ID

const MetaPixel = () => {
  const [loaded, setLoaded] = useState(false)
  const pathname = usePathname()

  useEffect(() => {
    if (!PIXEL_ID || !loaded) {
      return
    }

    // ИзвиквамеPageView евент при всяка промяна на страницата
    window.fbq('track', 'PageView')

  }, [pathname, loaded])

  return (
    <div>
      <Script
        id="fb-pixel"
        src="/scripts/pixel.js" // Локален скрипт, който зарежда fbq
        strategy="afterInteractive"
        onLoad={() => setLoaded(true)}
      />
    </div>
  )
}

export default MetaPixel
Създайте локален скрипт:

В папката public създайте нова папка scripts.

В public/scripts създайте нов файл pixel.js.

Поставете следния код в public/scripts/pixel.js:
