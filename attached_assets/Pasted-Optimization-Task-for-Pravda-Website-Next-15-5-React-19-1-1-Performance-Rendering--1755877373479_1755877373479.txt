Optimization Task for Pravda Website (Next 15.5 + React 19.1)
1. Performance & Rendering

 Активирай React Compiler (React Forget) – за автоматична мемоизация и по-малко re-renders.

 Ползвай use hook + React Server Components (RSC) за всички fetch-и към WordPress API и internal API-та.

 Настрой Partial Prerendering (PPR) в Next.js 15.5, за да намалиш TTFB при campaign pages.

 Провери дали всички <Image> компоненти са с priority само за LCP елементи, останалото да е lazy.

2. Bundling & Code Splitting

 Раздели големи UI/animation библиотеки (framer-motion, embla-carousel) чрез dynamic import с ssr: false.

 Пусни @next/bundle-analyzer след билд – елиминирай неоползвани Radix компоненти.

 Премахни dead code и извади rarely used calculators/case studies в отделни чанкове.

3. CSS & Styling

 Активирай Tailwind JIT purge → само реално използвани класове да влизат в production CSS.

 Уеднакви глобалните цветове и типография от design system (pravda-yellow, pravda-dark и т.н.).

 Изнеси critical CSS за Hero секциите директно в <head> (inlining).

4. Images & Media

 Потвърди, че AVIF/WebP вече работят (ок е) – качвай само оригинали с високо качество, Next.js ще прави останалото.

 Добави blurDataURL placeholders за всички hero/above-the-fold изображения.

 Генерирай OG изображения автоматично (src/app/og/route.tsx) вместо статични PNG.

5. Caching & Edge

 Настрой ISR (Incremental Static Regeneration) за services/ и blog/ → revalidate: 60–300 секунди.

 Използвай Vercel Edge Functions за API endpoints с висока честота (WordPress posts, calculators).

 Провери Service Worker (public/sw.js) да кешира статични assets + API responses.

6. Accessibility & SEO

 Проверявай всички бутони и линкове да имат aria-labels.

 Добави JSON-LD schemas (Service, Organization, Article) към всяка страница.

 Използвай next-seo за canonical, OG, Twitter.

 Следи Lighthouse → SEO 95+, Mobile Perf 90+.

7. Monitoring & Analytics

 Активирай Vercel Speed Insights + GA4 custom events (contact_form_submit, calculator_complete).

 Увери се, че Meta Pixel и Clarity се зареждат асинхронно, не блокират render-а.

8. Security

 Актуализирай CSP хедърите – премахни unsafe-inline където е възможно.

 Добави Subresource Integrity (SRI) за външни скриптове.
