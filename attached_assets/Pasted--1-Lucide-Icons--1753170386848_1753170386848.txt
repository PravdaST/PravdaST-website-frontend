Препоръки за библиотеки с икони
1. Lucide Icons
Това е една от най-препоръчваните модерни библиотеки. Lucide е наследник на популярната библиотека Feather Icons, но с много повече икони и активна поддръжка.

Предимства:

✨ Модерен и изчистен дизайн: Иконите са стилни и консистентни.

🚀 Лека и бърза: Оптимизирана е за производителност и зарежда само иконите, които използвате (tree-shaking).

🔧 Лесна за персонализиране: Можете лесно да променяте размер, цвят и дебелина на линията.

Инсталация:

Bash

npm install lucide-react
Пример за употреба:

JavaScript

import { CheckCircle } from 'lucide-react';

const MyComponent = () => {
  return (
    <div>
      <h3>Успешно <CheckCircle color="green" size={24} /></h3>
    </div>
  );
};
2. Heroicons
Създадена от екипа зад Tailwind CSS, тази библиотека е перфектен избор, ако използвате Tailwind в проекта си. Иконите са с изчистен и професионален вид.

Предимства:

Перфектна интеграция с Tailwind CSS: Създадени да работят безпроблемно заедно.

Два стила: Предлага два варианта за всяка икона – outline (контур) и solid (запълнена).

Висококачествен дизайн: Създадени от дизайнерите на Tailwind Labs.

Инсталация:

Bash

npm install @heroicons/react
Пример за употреба:

JavaScript

import { BeakerIcon } from '@heroicons/react/24/solid'; // или '/24/outline'

const MyComponent = () => {
  return (
    <div>
      <h4>Наука! <BeakerIcon className="h-6 w-6 text-blue-500" /></h4>
    </div>
  );
};
3. React Icons
Това е "всичко в едно" библиотека. Тя обединява множество популярни пакети с икони (включително Font Awesome, Material Design, Ant Design и много други) в един лесен за използване пакет.

Предимства:

Огромен избор: Достъп до хиляди икони от различни колекции.

Лесна употреба: Единен начин за импортиране на икони от различни библиотеки.

Оптимизация: Както и Lucide, тя включва в крайния пакет само иконите, които реално използвате.

Инсталация:

Bash

npm install react-icons
Пример за употреба:

JavaScript

import { FaBeer } from 'react-icons/fa'; // Икона от Font Awesome
import { MdAlarm } from 'react-icons/md'; // Икона от Material Design

const MyComponent = () => {
  return (
    <div>
      <p>Време е за <FaBeer /></p>
      <p>Не забравяй алармата <MdAlarm /></p>
    </div>
  );
};
Коя да изберете?
За най-добър баланс между модерен вид, производителност и лесна употреба, Lucide е отличен избор.

Ако вече използвате Tailwind CSS, Heroicons е най-логичният и добре интегриран вариант.

Ако имате нужда от голямо разнообразие от стилове и икони и искате всичко в един пакет, React Icons е чудесно решение.
