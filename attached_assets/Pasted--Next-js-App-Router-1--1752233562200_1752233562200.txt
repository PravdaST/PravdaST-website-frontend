задачата: Цялостна и финална адаптация на проекта към Next.js App Router

1. Контекст и цел:
Проектът е мигриран, но все още има множество малки грешки, свързани с новата архитектура. Целта е да се извърши пълен, систематичен преглед и корекция на целия код в src папката, за да се постигне пълна съвместимост и работещо приложение.

2. План за изпълнение:

Стъпка 1: Поправка на конфликта metadata / "use client"

Прегледай всички файлове с име page.tsx в директорията src/app и нейните под-директории.

Ако даден page.tsx файл едновременно експортира metadata И използва React Hooks (useState, useEffect и др.), приложи следната реструктуризация:

Създай нов файл в същата папка с име, завършващо на Client.tsx (например ClickstarterClient.tsx).

Премести цялата визуална част (всички import-и на компоненти и целият return стейтмънт) от page.tsx в новия ...Client.tsx файл.

Добави "use client"; в началото на новия ...Client.tsx файл.

Редактирай оригиналния page.tsx така, че той да съдържа само export const metadata = {...} и да връща новия ...Client.tsx компонент.

Стъпка 2: Гарантирай "use client"; за всички интерактивни компоненти

Прегледай всички .tsx файлове в папките src/components и src/hooks.

За всеки файл, провери дали съдържа React Hooks или обработва събития (onClick, onChange).

Ако отговорът е "да" и файлът все още няма "use client"; в началото, добави "use client"; на първия ред.

Стъпка 3: Провери за остарели импорти и HTML структура

Направи глобално търсене в целия проект за текста "wouter". Ако намериш import от wouter, замени го с import Link from 'next/link'.

Направи глобално търсене за <Link. Провери дали някой от <Link> компонентите има <a> таг като свое дете. Ако намериш, премахни <a> тага.

Стъпка 4: Финална проверка на конфигурацията

Увери се, че tailwind.config.ts съдържа правилните пътища в content секцията (./src/pages, ./src/components, ./src/app).

Увери се, че postcss.config.js има правилното съдържание: module.exports = { plugins: { tailwindcss: {}, autoprefixer: {} } };

Увери се, че в package.json не присъстват пакетите wouter и react-helmet-async.
