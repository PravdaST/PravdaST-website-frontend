# Правдаст - Next.js Business Engineering Platform

Comprehensive business engineering website for Pravdast Agency, featuring four proprietary business systems for predictable business growth.

## 🚀 Features

- **SEO Struktor™** - Technical SEO optimization system
- **Trendlab™** - Content creation and storytelling platform  
- **Clickstarter™** - Paid advertising optimization system
- **Clientomat™** - Client communication automation system

## 📊 Technical Stack

- **Framework:** Next.js 15.3.5 with App Router
- **Styling:** Tailwind CSS + shadcn/ui
- **Animations:** Framer Motion
- **Database:** PostgreSQL with Drizzle ORM
- **Email:** SendGrid integration
- **Marketing:** Klaviyo automation
- **Deployment:** Vercel Ready
