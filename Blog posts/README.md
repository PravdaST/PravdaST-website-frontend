# Blog Posts Directory

Тази папка съдържа всички blog статии във формат Markdown (.md).

## Как да добавите нова статия:

### Опция 1: Обикновен .md файл (препоръчва се)
Просто създайте .md файл с вашето съдържание. Системата автоматично ще генерира всички необходими метаданни:

```markdown
# Заглавието на статията

Съдържанието на статията тук...
```

### Опция 2: .md файл с front matter (за напреднали)
```markdown
---
title: "Заглавието на статията"
excerpt: "Кратко описание на статията (150-200 символа)"
category: "Категория (напр. Бизнес стратегии, SEO, Автоматизация)"
tags: ["tag1", "tag2", "tag3"]
publishedAt: "2025-01-22T12:00:00Z"
readTime: 10
author: "Pravda Agency"
slug: "url-friendly-slug"
---

# Заглавието на статията

Съдържанието на статията тук...
```

## Автоматично генериране на метаданни:

Ако не добавите front matter, системата автоматично ще генерира:

- **title**: От първия ред (ако започва с #) или от името на файла
- **excerpt**: От първите 150-200 символа на съдържанието
- **slug**: URL-friendly версия на заглавието
- **category**: "Бизнес стратегии" (по подразбиране)
- **tags**: ["бизнес инженерство", "растеж", "автоматизация"]
- **readTime**: Автоматично изчислено според дължината на текста
- **publishedAt**: Днешната дата
- **author**: "Pravda Agency"

Файловете се обработват автоматично и се появяват в blog-a веднага!
