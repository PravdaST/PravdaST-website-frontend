# Airtable Setup за GLOVO Calculator

## Таблица: Fast Food

### Полета, които трябва да създадете в Airtable:

1. **Restaurant Name** (Single line text)
   - Име на ресторанта

2. **Daily Orders** (Single select)
   - Options:
     - 5-10
     - 11-20
     - 21-35
     - 36-50
     - 50+

3. **Average Order Value** (Single select)
   - Options:
     - 15-25
     - 26-35
     - 36-50
     - 50+

4. **Email** (Email)
   - Имейл адрес на клиента

5. **Phone** (Phone number)
   - Телефонен номер

6. **Timestamp** (Date and time)
   - Кога е подадена формата

7. **Created** (Created time)
   - Автоматично създаване на запис

## Инструкции:

1. Отворете вашата Airtable база
2. Отидете в таблицата "Fast Food"
3. Създайте полетата горе с правилните типове
4. Подайте Base ID на разработчика за финализиране на интеграцията
