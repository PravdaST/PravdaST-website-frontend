# Project Documentation

Тази папка съдържа всички документационни файлове за Pravdast website project.

- `FINAL_SECURITY_CLEANUP.md` - Security audit и премахване на sensitive данни
- `SECURITY_AUDIT_FINAL.md` - Финален security report
- `VERCEL_ENVIRONMENT_SETUP.md` - Environment variables конфигурация

- `SIMPLE_GIT_FIX.md` - Опростени Git команди

- `DEPLOYMENT_GUIDE.md` - Пълен deployment guide
- `VERCEL_DEPLOYMENT_FIX.md` - Vercel deployment fixes
- `VERCEL_BUILD_ERROR_FIX.md` - Build error solutions
- `VERCEL_SETTINGS_FIX.md` - Vercel настройки

### 📊 Project Status
- `PROJECT_STATUS.md` - Текущо състояние на проекта
